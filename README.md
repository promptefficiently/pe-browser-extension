# Prompt Efficiently browser extension

Shows a rough usage estimate beside your prompt on supported AI chat, builder and developer-console sites, in desktop Chrome. Estimates are a guide, not a prediction of your bill or remaining allowance.

- Sign-in to a free Prompt Efficiently account is required (https://promptefficiently.com). Sign-in, rewrites and billing run on Prompt Efficiently's servers and are not part of this repository.
- Manual installation: unzip, open chrome://extensions, turn on Developer mode, choose "Load unpacked".
- Prompt Efficiently is not affiliated with the AI products it supports. Logos and names belong to their owners.
